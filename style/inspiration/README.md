Drop reference images here (png/jpg/webp/gif) — mood boards, screenshots,
comps like Journey/Gris frames — then re-run:
    python style/make_visual_guide.py
They render in the guide's Inspiration section, filename as caption.
This folder is yours; the generator only reads it.

Everything here except this README and CREDITS.txt is gitignored: reference
frames are other people's work and stay a private mood board on your machine.
Name files with a prefix listed in CREDITS.txt (e.g. o-empire-01.png) so the
guide captions them with the credit and link.
